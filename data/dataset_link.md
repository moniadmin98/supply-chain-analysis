-Fuente de datos

En este proyecto se utilizo el dataset "DataCo Smart Supply Chain for Big Data Analysis", 
disponible públicamente en Kaggle:

https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis

El archivo CSV no se incluye en este repositorio por su tamaño. 
Para reproducir el análisis, descarga `DataCoSupplyChainDataset.csv` desde el link 
anterior e importelo a SQL Server siguiendo los pasos documentados en el README.
